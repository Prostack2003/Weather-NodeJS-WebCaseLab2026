# Консольная утилита на Node.js для работы с внешним REST API

Это учебный проект 1-ой недели по заданию Case Lab.
<br> Консольная утилита "Погодный дайджест" на Node.js, которая:

1. Принимает город или список городов.
2. Получает прогноз погоды из открытого REST API.
3. Выводит результат в читаемом виде в терминал.
4. Сохраняет отчет в файл.

Если завершается с ошибкой, то сообщает понятную причину
пользователю об этом.

## Установка

1.  Клонируйте репозиторий:
    ```bash
    git clone https://github.com/Prostack2003/Weather-NodeJS-WebCaseLab2026.git
    ```
2.  Установите необходимые зависимости из package.json:
    ```bash
    npm install
    ```
